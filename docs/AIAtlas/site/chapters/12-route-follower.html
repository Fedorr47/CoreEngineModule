    12. RouteFollower: сегменты, look-ahead, плоскость перехода и прибытие¶

    Коротко

    GameplayRouteFollower превращает ломаную GameplayRoute в покадровое намерение движения. Он хранит индекс текущего сегмента, на промежуточных точках использует Arrival с радиусом замедления, равным радиусу приёма (без торможения в углах), на финише — настроенный радиус замедления. У углов включается look-ahead: виртуальная цель скользит по следующему сегменту, а сегмент переключается, когда агент пересёк плоскость перехода по биссектрисе угла. Аннотированный сегмент передаёт управление traversal. Статус: SOURCE_VERIFIED; числовые примеры пересчитаны tools/verify_examples.py.

    1. Задача и интуиция¶

    Если вести агента по ломаной, просто направляя его в очередную точку, он будет подходить к каждому углу «носом», замедляться (если использовать Arrival) или проскакивать точку и разворачиваться. Нужны три свойства: непрерывное движение через промежуточные точки, плавное срезание углов и точная остановка только в конце. Кроме того, follower должен понимать, что некоторые сегменты проходятся не шагом, а прыжком или через дверь.

    2. Теоретическая выкладка¶

    2.1. Модель: автомат над индексом сегмента¶

    Маршрут — точки P0,…,PnP_0, \dots, P_nP0​,…,Pn​ и аннотации A0,…,An−1A_0, \dots, A_{n-1}A0​,…,An−1​ (сегмент iii — от PiP_iPi​ к Pi+1P_{i+1}Pi+1​). Follower хранит iii и на каждом тике выбирает цель steering. P0P_0P0​ — якорь: follower не добавляет сегмент от текущей позиции агента к P0P_0P0​ и сразу ведёт к P1P_1P1​ (RF-START).

    2.2. Прибытие к промежуточным и конечной точкам¶

    Для сегмента iii цель — угол C=Pi+1C = P_{i+1}C=Pi+1​, steering — Arrival (глава 13) с параметрами

    ri=r,Ri={R,i=n−1  (финальный сегмент),r,иначе. r_i = r, \qquad R_i = \begin{cases} R, & i = n-1 \;(\text{финальный сегмент}),\\ r, & \text{иначе}. \end{cases} ri​=r,Ri​={R,r,​i=n−1(финальный сегмент),иначе.​

    При Ri=rR_i = rRi​=r интервал замедления вырожден, и Arrival даёт magnitude 1 вплоть до входа в r+0.001r + 0.001r+0.001: в промежуточных точках агент не тормозит (RF-SLOWING). Как только угол «достигнут», iii увеличивается, и цикл продолжается в том же тике — несколько совпадающих или очень близких точек проходятся за один кадр.

    2.3. Look-ahead: вывод виртуальной цели¶

    Хотим, чтобы у угла агент целился не в сам угол, а немного «за угол», причём тем дальше, чем ближе он к углу. Пусть ppp — позиция агента в XZ, CCC — угол, u^out\hat u_{\text{out}}u^out​ — единичное направление следующего сегмента, ℓout\ell_{\text{out}}ℓout​ — его длина, LLL — дистанция look-ahead (0.75 по умолчанию, RF-SETTINGS), d=∥C−p∥xzd = \lVert C - p\rVert_{xz}d=∥C−p∥xz​. Потребуем: (1) при d=Ld = Ld=L виртуальная цель совпадает с углом (непрерывность с обычным наведением); (2) при приближении к углу цель отодвигается по исходящему сегменту на столько же, на сколько сократилась дистанция; (3) цель не выходит за конец сегмента. Отсюда

    q=C+u^out⋅min⁡ ⁣(L−d,  ℓout),d<L. q = C + \hat u_{\text{out}} \cdot \min\!\big(L - d,\; \ell_{\text{out}}\big), \qquad d < L . q=C+u^out​⋅min(L−d,ℓout​),d<L.

    Свойство (2) означает, что «длина нити» d+∥q−C∥=Ld + \lVert q - C \rVert = Ld+∥q−C∥=L постоянна, пока цель не упрётся в конец сегмента. Высота qqq берётся от угла. К qqq применяется Seek с нулевым радиусом приёма (полная magnitude). Look-ahead не применяется, если L≤0L \le 0L≤0, если следующего сегмента нет или он аннотирован traversal, если входящий или исходящий сегмент вырожден (≤10−6\le 10^{-6}≤10−6 м в XZ) или если d≥Ld \ge Ld≥L (RF-LOOKAHEAD).

    2.4. Плоскость перехода: когда угол пройден¶

    Попадание в маленький радиус rrr при срезании угла может не случиться: агент проходит в стороне от точки. Нужен критерий «угол пройден» без попадания. Пусть u^in\hat u_{\text{in}}u^in​ — направление входящего сегмента. Возьмём нормаль

    n^=u^in+u^out∥u^in+u^out∥ \hat n = \frac{\hat u_{\text{in}} + \hat u_{\text{out}}}{\lVert \hat u_{\text{in}} + \hat u_{\text{out}} \rVert} n^=∥u^in​+u^out​∥u^in​+u^out​​

    — биссектрису между направлениями «вдоль входящего» и «вдоль исходящего». Плоскость через угол с нормалью n^\hat nn^ делит окрестность угла на «до» и «после»: для прямого продолжения (u^in=u^out\hat u_{\text{in}} = \hat u_{\text{out}}u^in​=u^out​) это обычная торцевая плоскость сегмента, для поворота на 90° — диагональ под 45°. Угол считается пройденным, если

    (p−C)⋅n^≥0и∥p−C∥xz≤L. (p - C)\cdot \hat n \ge 0 \quad\text{и}\quad \lVert p - C \rVert_{xz} \le L . (p−C)⋅n^≥0и∥p−C∥xz​≤L.

    Ограничение ≤L\le L≤L («конверт») не даёт засчитать проход агенту, который оказался по нужную сторону плоскости, но далеко от угла. При развороте почти на 180° сумма направлений вырождается (∥u^in+u^out∥2≤10−12\lVert \hat u_{\text{in}} + \hat u_{\text{out}}\rVert^2 \le 10^{-12}∥u^in​+u^out​∥2≤10−12), и нормалью служит u^in\hat u_{\text{in}}u^in​ (RF-PASSED). Переключение по плоскости разрешено не более одного раза за тик и только когда look-ahead применим: это защищает от «проскакивания» цепочки близких углов за один кадр без реального движения.

    2.5. Traversal-сегменты¶

    Если у текущего сегмента есть traversalLink, follower переходит в TraversalRequired и отдаёт handle; движение по сегменту выполняет внешний исполнитель. После его успеха CompleteTraversal(handle) проверяет, что завершён тот же link, и продвигает индекс (глава 16) (RF-COMPLETE).

            [[nodiscard]] GameplayRouteFollowerOutput Tick(
            const mathUtils::Vec3& currentPosition)
        {
            GameplayRouteFollowerOutput output{};
            output.status = status_;

            if (status_ == GameplayRouteFollowerStatus::TraversalRequired)
            {
                output.requiredTraversalLink = GetCurrentTraversalLink();
                return output;
            }

            if (status_ != GameplayRouteFollowerStatus::Following)
            {
                return output;
            }

            bool bAdvancedByLookAhead = false;

            while (currentSegmentIndex_ < route_.segmentAnnotations.size())
            {
                const GameplayRouteSegmentAnnotation& annotation = 
                    route_.segmentAnnotations[currentSegmentIndex_];

                if (annotation.traversalLink.has_value())
                {
                    status_ = GameplayRouteFollowerStatus::TraversalRequired;
                    output.status = status_;
                    output.requiredTraversalLink = annotation.traversalLink;
                    return output;
                }

                const bool bIsFinalSegment = currentSegmentIndex_ + 1u == route_.segmentAnnotations.size();

                GameplayArrivalSteeringSettings segmentSteeringSettings = steeringSettings_;
                segmentSteeringSettings.slowingRadius = bIsFinalSegment
                    ? steeringSettings_.slowingRadius
                    : steeringSettings_.acceptanceRadius;

                const mathUtils::Vec3& cornerPosition = route_.points[currentSegmentIndex_ + 1u].worldPosition;
                const GameplaySteeringOutput cornerSteering = BuildGameplayArrivalSteering(
                    currentPosition,
                    cornerPosition,
                    segmentSteeringSettings);

                if (cornerSteering.status == GameplaySteeringStatus::Arrived)
                {
                    ++currentSegmentIndex_;
                    continue;
                }

                mathUtils::Vec3 steeringTarget = cornerPosition;
                const bool bCanLookAhead = TryBuildLookAheadTarget_(
                    currentPosition,
                    steeringTarget);

                if (!bAdvancedByLookAhead &&
                    bCanLookAhead &&
                    HasPassedCurrentCorner_(currentPosition))
                {
                    bAdvancedByLookAhead = true;
                    ++currentSegmentIndex_;
                    continue;
                }

                const GameplaySteeringOutput steering = bCanLookAhead
                    ? BuildGameplaySeekSteering(
                        currentPosition,
                        steeringTarget,
                        GameplaySeekSteeringSettings{
                            .acceptanceRadius = 0.0f,
                            .wantsRun = steeringSettings_.wantsRun })
                    : cornerSteering;

                if (steering.status == GameplaySteeringStatus::Moving)
                {
                    const bool bHasMovementIntent = steering.movement.IsMoving();
                    assert(bHasMovementIntent && "Moving steering status must provide a non-zero movement intent.");
                    output.status = GameplayRouteFollowerStatus::Following;
                    output.movement = steering.movement;
                    return output;
                }

                // A degenerate virtual target cannot provide a direction. Keep
                // the authoritative segment and fall back to its corner intent.
                output.status = GameplayRouteFollowerStatus::Following;
                output.movement = cornerSteering.movement;
                return output;
            }

            status_ = GameplayRouteFollowerStatus::Succeeded;
            output.status = status_;
            return output;
        }

             [[nodiscard]] bool TryBuildLookAheadTarget_(
            const mathUtils::Vec3& currentPosition,
            mathUtils::Vec3& steeringTarget) const noexcept
        {
            const float lookAheadDistance = followerSettings_.cornerLookAheadDistance;
            const std::size_t nextSegmentIndex = currentSegmentIndex_ + 1u;
            if (lookAheadDistance <= 0.0f ||
                nextSegmentIndex >= route_.segmentAnnotations.size() ||
                route_.segmentAnnotations[nextSegmentIndex].traversalLink.has_value())
            {
                return false;
            }

            const mathUtils::Vec3& corner = route_.points[currentSegmentIndex_ + 1u].worldPosition;
            const mathUtils::Vec3& next = route_.points[currentSegmentIndex_ + 2u].worldPosition;
            mathUtils::Vec3 incoming = corner - route_.points[currentSegmentIndex_].worldPosition;
            incoming.y = 0.0f;
            mathUtils::Vec3 outgoing = next - corner;
            outgoing.y = 0.0f;
            const float incomingLength = mathUtils::Length(incoming);
            const float outgoingLength = mathUtils::Length(outgoing);
            if (!std::isfinite(incomingLength) || incomingLength <= mathUtils::kLengthEpsilon ||
                !std::isfinite(outgoingLength) || outgoingLength <= mathUtils::kLengthEpsilon)
            {
                return false;
            }

            mathUtils::Vec3 toCorner = corner - currentPosition;
            toCorner.y = 0.0f;
            const float cornerDistance = mathUtils::Length(toCorner);
            if (!std::isfinite(cornerDistance) || cornerDistance >= lookAheadDistance)
            {
                return false;
            }

            const float distanceAlongNext = std::min(
                lookAheadDistance - cornerDistance,
                outgoingLength);
            steeringTarget = corner + outgoing * (distanceAlongNext / outgoingLength);
            steeringTarget.y = corner.y;
            return true;
        }

        [[nodiscard]] bool HasPassedCurrentCorner_(
            const mathUtils::Vec3& currentPosition) const noexcept
         {
             const std::size_t nextSegmentIndex = currentSegmentIndex_ + 1u;
             if (nextSegmentIndex >= route_.segmentAnnotations.size())
             {
                 return false;
             }

             const mathUtils::Vec3& start = route_.points[currentSegmentIndex_].worldPosition;
             const mathUtils::Vec3& corner = route_.points[currentSegmentIndex_ + 1u].worldPosition;
             const mathUtils::Vec3& next = route_.points[currentSegmentIndex_ + 2u].worldPosition;

             mathUtils::Vec3 incoming = corner - start;
             incoming.y = 0.0f;
             mathUtils::Vec3 outgoing = next - corner;
             outgoing.y = 0.0f;


             const float incomingLength = mathUtils::Length(incoming);
             const float outgoingLength = mathUtils::Length(outgoing);
             if (!std::isfinite(incomingLength) ||
                 incomingLength <= mathUtils::kLengthEpsilon ||
                 !std::isfinite(outgoingLength) ||
                 outgoingLength <= mathUtils::kLengthEpsilon)

             {
                 return false;
             }

             mathUtils::Vec3 fromCorner = currentPosition - corner;
             fromCorner.y = 0.0f;
             const float cornerDistance = mathUtils::Length(fromCorner);
             const bool bInsideEnvelope = std::isfinite(cornerDistance) &&
                 cornerDistance <= followerSettings_.cornerLookAheadDistance;

             const mathUtils::Vec3 incomingDirection = incoming / incomingLength;
             const mathUtils::Vec3 outgoingDirection = outgoing / outgoingLength;
             mathUtils::Vec3 transitionNormal = incomingDirection + outgoingDirection;
             const float transitionNormalLengthSquared =
                 mathUtils::Dot(transitionNormal, transitionNormal);

             if (!mathUtils::IsFinite(transitionNormal) ||
                 transitionNormalLengthSquared <= mathUtils::kLengthEpsilonSq)
             {
                 // Near-180-degree reversals have no stable angle bisector.
                 // Preserve the previous incoming end-plane behavior.
                 transitionNormal = incomingDirection;
             }
             else
             {
                 transitionNormal =
                     transitionNormal / std::sqrt(transitionNormalLengthSquared);
             }

             const bool bCrossedTransitionPlane =
                 mathUtils::Dot(fromCorner, transitionNormal) >= 0.0f;
             return bInsideEnvelope && bCrossedTransitionPlane;
         }

    4.3. Где вызывается¶

    AIFollowRouteActionRuntime::AdvanceFollower_ вызывает Tick каждый tick задачи (кроме времени активного traversal), копирует physicallyBlocked из состояния движения и применяет намерение через avoidance (если есть query) и ApplyGameplayMovementIntent (NA-ROUTE-ADVANCE, NA-ROUTE-APPLY). Терминальные статусы останавливают движение с сохранением вертикальной скорости (NA-ROUTE-STOP).

    6. Типичные ошибки, границы и проверка¶

    • Ожидать сегмент от агента к P0P_0P0​. Его нет: агент, стоящий далеко от P0P_0P0​, сразу пойдёт к P1P_1P1​.
    • Ожидать завершения при «перелёте» финиша. Плоскость перехода работает только для промежуточных углов; финиш — только по arrival. Если тело физически не входит в rrr, маршрут не завершится.
    • Look-ahead перед traversal. Отключён специально: подход к прыжку/двери идёт точно в точку.
    • Слишком большой LLL на коротких сегментах. Цель упирается в конец сегмента (min⁡\minmin), а плоскость может засчитать угол рано; уменьшайте LLL или удлиняйте сегменты.
    • 3D против XZ. Все расстояния follower — горизонтальные; высота точек влияет только на q.yq.yq.y.

    Проверки: TestGameplayRouteFollower.cpp (34), TestAIFollowRouteActionRuntime.cpp (20) — наличие SOURCE_VERIFIED; численные случаи — tools/verify_examples.py (раздел follower).
