    11. Пространственные маршруты: GOAP-план против маршрута, графы, NavMesh, route cost¶

    Коротко

    План отвечает на вопрос «какие действия», маршрут — «через какие точки». В CoreEngine маршрут GameplayRoute — ломаная из точек и аннотаций сегментов (N точек ↔ N−1 аннотаций). Он приходит из двух источников: авторского графа .routes.json (Дейкстра по ролям уровня, используется GOAP move_to) или NavMesh Recast/Detour (только прямые запуски, сценарий Maze). Стоимость маршрута может стать стоимостью GOAP-действия (routeCost), но вычисляется один раз при создании instance. Статус: SOURCE_VERIFIED.

    1. Задача и интуиция¶

    Шаг move_to/start_to_coin_c — одно символическое действие, но в мире это путь в несколько метров, возможно с поворотами, прыжком или дверью. GOAP не должен знать о геометрии, а исполнитель движения — о монетах и ключах. Маршрут — промежуточное представление: упорядоченные мировые точки плюс пометки, какой сегмент проходится обычным steering, а какой — специальным исполнителем (traversal).

    2. Теоретическая выкладка¶

    2.1. Два уровня поиска¶

    Получается иерархическое планирование в упрощённой форме: верхний уровень (GOAP) ищет в пространстве символических состояний, нижний (route search) — в пространстве мест. Связь — через стоимость:

    c(move_to/k)=min⁡путь sk→tk∑e∈путьw(e), c(\texttt{move\_to}/k) = \min_{\text{путь } s_k \to t_k} \sum_{e \in \text{путь}} w(e), c(move_to/k)=путь sk​→tk​min​e∈путь∑​w(e),

    где sks_ksk​, tkt_ktk​ — узлы-роли контекста kkk, w(e)w(e)w(e) — стоимость ребра. Важно: это предвычисление при создании instance, а не совместный поиск. Если путь изменится (дверь закроется, агент сдвинется), стоимость в GOAP не обновится.

    2.2. Поиск на явном графе: Дейкстра с предшественниками¶

    FindWeightedGameplayRoute работает на явном ориентированном взвешенном графе (V,E,w)(V, E, w)(V,E,w) с w≥0w \ge 0w≥0:

    1. dist[s]=0\text{dist}[s] = 0dist[s]=0, остальные ∞\infty∞; очередь по (dist,порядок вставки)(\text{dist}, \text{порядок вставки})(dist,порядок вставки).
    2. Извлекаем вершину с минимальной дистанцией; устаревшие записи пропускаем; при извлечении цели — стоп.
    3. Релаксация: если dist[u]+w(u,v)<dist[v]\text{dist}[u] + w(u,v) < \text{dist}[v]dist[u]+w(u,v)<dist[v] — обновить dist[v]\text{dist}[v]dist[v], запомнить предшественника и ребро.
    4. Восстановление пути — проход по предшественникам от цели к старту и разворот.

    Отличие от GOAP-поиска главы 05: здесь вершины заранее известны и пронумерованы, поэтому вместо копии пути в каждом узле хранится массив предшественников — память O(∣V∣)O(|V|)O(∣V∣), время O((∣V∣+∣E∣)log⁡∣V∣)O((|V| + |E|)\log|V|)O((∣V∣+∣E∣)log∣V∣). Сравнение строгое (<): при равной стоимости остаётся первый найденный предшественник. Особые случаи: старт = цель → маршрут из одной точки, стоимость 0; цель недостижима → NoRoute; некорректный граф (дубликат ID, неконечная позиция, отрицательная стоимость, ребро к несуществующему узлу) → InvalidGraph.

    Направленность существенна: ребро A→BA \to BA→B не даёт B→AB \to AB→A. Стоимость ребра по умолчанию — 3D-длина между позициями ролей; явная cost заменяет её полностью.

    2.3. NavMesh: полигоны, коридор, «натянутая нить»¶

    NavMesh (Recast/Detour, M. Mononen) строится из статической геометрии: вокселизация, фильтрация непроходимого (уклон, высота потолка, ступени), эрозия проходимой области на радиус агента и разбиение на выпуклые полигоны. Эрозия — это сдвиг границы внутрь на rrr (сумма Минковского с диском): после неё центр агента может стоять в любой точке полигона, не задевая стен. Поэтому NavMesh зависит от размеров агента, и CoreEngine строит отдельный NavMesh на каждый различный профиль.

    Параметры переводятся в клетки консервативно (NV-CONFIG):

    rcells=⌈rcs⌉,hcells=⌈hch⌉,climbcells=⌊stepch⌋, r_{\text{cells}} = \left\lceil \frac{r}{c_s} \right\rceil,\quad h_{\text{cells}} = \left\lceil \frac{h}{c_h} \right\rceil,\quad \text{climb}_{\text{cells}} = \left\lfloor \frac{\text{step}}{c_h} \right\rfloor , rcells​=⌈cs​r​⌉,hcells​=⌈ch​h​⌉,climbcells​=⌊ch​step​⌋,

    где csc_scs​ — размер клетки по горизонтали, chc_hch​ — по вертикали. Радиус и высота округляются вверх (безопасно: агент не застрянет), допустимая ступень — вниз (безопасно: не потребует подъёма выше возможного).

    Запрос пути — три шага Detour (NV-FINDPATH):

    1. findNearestPoly в коробке полуразмеров searchExtents вокруг старта и цели;
    2. findPath — A по графу смежности полигонов → коридор* полигонов; при недостижимости Detour может вернуть частичный коридор до ближайшего полигона;
    3. findStraightPath — алгоритм «воронки» (string pulling) внутри коридора → угловые точки кратчайшей ломаной.

    CoreEngine отбрасывает частичный результат: если последний полигон коридора не совпадает с полигоном цели, это NoPath (NV-PARTIAL). Переполнение буферов (2048 полигонов/точек) — BufferTooSmall (NV-LIMITS). Наличие нескольких точек ещё не доказывает достижимость — её доказывает именно проверка последнего полигона.

        struct GameplayRoute
    {
        // Ordered world-space points. Segment annotation i describes travel
        // from points[i] to points[i + 1].
        std::vector<GameplayRoutePoint> points{};

       // Contains exactly one annotation for every pair of adjacent points.
       // An annotation without a traversal link represents ordinary movement.
        std::vector<GameplayRouteSegmentAnnotation> segmentAnnotations{};

        [[nodiscard]] bool IsEmpty() const noexcept
        {
            return points.empty() && segmentAnnotations.empty();
        }

        [[nodiscard]] constexpr bool IsValid() const noexcept
        {
            if (points.empty())
            {
                return segmentAnnotations.empty();
            }

            const std::size_t expectedSegmentCount = points.size() - 1u;
            const bool bHasExpectedSegmentCount = segmentAnnotations.size() == expectedSegmentCount;

            if (!bHasExpectedSegmentCount)
            {
                return false;
            }

            for (const GameplayRoutePoint& point : points)
            {
                const bool bHasFinitePosition =
                    std::isfinite(point.worldPosition.x) &&
                    std::isfinite(point.worldPosition.y) &&
                    std::isfinite(point.worldPosition.z);

                if (!bHasFinitePosition)
                {
                    return false;
                }
            }

            for (const GameplayRouteSegmentAnnotation& annotation : segmentAnnotations)
            {
                if (!annotation.IsValid())
                {
                    return false;
                }
            }

            return true;
        }
    };

        GameplayRouteSearchResult FindWeightedGameplayRoute(
        const GameplayRouteGraph& graph,
        const GameplayRouteNodeId startNodeId,
        const GameplayRouteNodeId goalNodeId)
    {
        if (!graph.IsValid())
        {
            return GameplayRouteSearchResult{.status = GameplayRouteSearchStatus::InvalidGraph};
        }

        const NodeIndexById nodeIndexById = BuildNodeIndexById(graph);

        const std::optional<std::size_t> startNodeIndex = FindNodeIndex(nodeIndexById, startNodeId);
        const std::optional<std::size_t> goalNodeIndex = FindNodeIndex(nodeIndexById, goalNodeId);

        const bool bHasValidStartNode = startNodeId.IsValid() && startNodeIndex.has_value();
        const bool bHasValidGoalNode = goalNodeId.IsValid() && goalNodeIndex.has_value();
        const bool bHasValidRequest = bHasValidStartNode && bHasValidGoalNode;

        if (!bHasValidRequest)
        {
            return GameplayRouteSearchResult{.status = GameplayRouteSearchStatus::InvalidRequest};
        }

        const std::size_t resolvedStartNodeIndex = *startNodeIndex;
        const std::size_t resolvedGoalNodeIndex = *goalNodeIndex;

        if (resolvedStartNodeIndex == resolvedGoalNodeIndex)
        {
            GameplayRoute route{ .points = 
                {GameplayRoutePoint
                    {.worldPosition = graph.nodes[resolvedStartNodeIndex].worldPosition}
                }
            };

            return GameplayRouteSearchResult{
                .status = GameplayRouteSearchStatus::Succeeded,
                .route = std::move(route),
                .totalCost = 0.0f
            };
        }

        std::vector<std::vector<std::size_t>> outgoingEdgeIndices(graph.nodes.size());

        for (std::size_t edgeIndex = 0u; edgeIndex  < graph.edges.size(); ++edgeIndex)
        {
            const GameplayRouteGraphEdge& edge = graph.edges[edgeIndex];
            const std::size_t fromNodeIndex = nodeIndexById.at(edge.fromNodeId.value);
            outgoingEdgeIndices[fromNodeIndex].push_back(edgeIndex);
        }

        std::vector<float> accumulatedCosts(graph.nodes.size(), std::numeric_limits<float>::infinity());
        std::vector<std::size_t> predecessorNodeIndices(graph.nodes.size(), kInvalidNodeIndex);
        std::vector<std::size_t> predecessorEdgeIndices(graph.nodes.size(), kInvalidNodeIndex);

        GameplayRouteSearchQueue queue{};
        std::size_t nextInsertionOrder = 0u;

        accumulatedCosts[resolvedStartNodeIndex] = 0.0f;

        queue.push(GameplayRouteSearchQueueEntry{
            .accumulatedCost = 0.0f, 
            .nodeIndex =  resolvedStartNodeIndex, 
            .insertionOrder = nextInsertionOrder++});

        while (!queue.empty())
        {
            const GameplayRouteSearchQueueEntry currentEntry = queue.top();
            queue.pop();

            const bool bIsStaleEntry = currentEntry.accumulatedCost != accumulatedCosts[currentEntry.nodeIndex];

            if (bIsStaleEntry)
            {
                continue;
            }

            if (currentEntry.nodeIndex == resolvedGoalNodeIndex)
            {
                break;
            }

            for (const std::size_t edgeIndex : outgoingEdgeIndices[currentEntry.nodeIndex])
            {
                const GameplayRouteGraphEdge& edge = graph.edges[edgeIndex];
                const std::size_t destinationNodeIndex = nodeIndexById.at(edge.toNodeId.value);
                const float candidateCost = currentEntry.accumulatedCost + edge.cost;
                const bool bHasLowerCost = candidateCost < accumulatedCosts[destinationNodeIndex];

                if (!bHasLowerCost)
                {
                    continue;
                }

                accumulatedCosts[destinationNodeIndex] = candidateCost;
                predecessorNodeIndices[destinationNodeIndex] = currentEntry.nodeIndex;
                predecessorEdgeIndices[destinationNodeIndex] = edgeIndex;

                queue.push(GameplayRouteSearchQueueEntry{
                .accumulatedCost = candidateCost,
                .nodeIndex = destinationNodeIndex,
                .insertionOrder = nextInsertionOrder++});
            }
        }

        const float goalCost = accumulatedCosts[resolvedGoalNodeIndex];

        AuthoredGraph CompileGraph(const GameplayGOAPCompositionContext& context)
    {
        AuthoredGraph result;
        const auto& asset = *context.routeGraph;
        for (const auto& name : asset.nodes)
        {
            const GameplayRouteNodeId id{result.nodes.size() + 1u};
            if (!result.nodes.emplace(name, id).second)
            {
                context.Fail(asset.source, "duplicate route node '" + name + "'");
            }
            result.graph.nodes.push_back({id, context.Role(name).position});
        }
        for (const auto& edge : asset.edges)
        {
            const auto from = result.nodes.find(edge.from), to = result.nodes.find(edge.to);
            if (from == result.nodes.end() || to == result.nodes.end())
            {
                context.Fail(asset.source, "route edge references an unknown node");
            }
            const float cost = edge.cost.value_or(mathUtils::Length(
                context.Role(edge.to).position - context.Role(edge.from).position));
            GameplayRouteSegmentAnnotation annotation{};
            if (!edge.traversal.empty())
            {
                if (context.levelBindings == nullptr)
                {
                    context.Fail(asset.source, "missing traversal bindings");
                }
                const auto& entries = context.levelBindings->traversals;
                const auto binding = std::ranges::find(entries, edge.traversal, &GameplayAITraversalBindingAsset::name);
                if (binding == entries.end()
                    || std::ranges::count(entries, edge.traversal, &GameplayAITraversalBindingAsset::name) != 1)
                {
                    context.Fail(edge.traversal, "missing or ambiguous traversal binding");
                }
                const GameplayTraversalTypeId type = binding->type == "jump" ? kJumpTraversalTypeId
                    : binding->type == "door" ? kDoorTraversalTypeId : GameplayTraversalTypeId{};
                const GameplayTraversalLinkHandle handle{binding->handle};
                const auto link = context.services.traversalLinkRegistry.Find(handle);
                if (!type.IsValid() || !link || !link->IsValid() || link->traversalTypeId != type
                    || link->targetEntity != context.Role(binding->target).entity)
                {
                    context.Fail(edge.traversal, "unresolved traversal link or target/type mismatch");
                }
                annotation.traversalLink = handle;
            }
            result.graph.edges.push_back({from->second, to->second, cost, annotation});
        }
        if (!result.graph.IsValid())
        {
            context.Fail(asset.source, "invalid route graph");
        }
        return result;
    }

    4.5. NavMesh¶

    Геометрия — статические меши уровня в мировых координатах с учётом зеркальных трансформаций (NV-GEOM-BUILD); bake выполняет appNavigationCoordinator::Advance, когда меши загружены (AP-NAV-COORD): сначала профиль по умолчанию, затем профили всех node-bound персонажей. Новый профиль может быть построен синхронно при ResolveProfile с невиданными ранее параметрами (NV-PROFILES). Debug-overlay NavMesh рисует геометрию профиля по умолчанию.

    5. Разобранный пример¶

    Maze (AS-SC-MAZE): агент с физическими параметрами r=0.35r = 0.35r=0.35, цилиндр 1.1 (полная высота 1.1+2⋅0.35=1.81.1 + 2\cdot0.35 = 1.81.1+2⋅0.35=1.8), ступень 0.35, уклон 45°. Bake по умолчанию: cs=0.2c_s = 0.2cs​=0.2, ch=0.1c_h = 0.1ch​=0.1 (NV-BUILD-SETTINGS). Клетки профиля агента: радиус ⌈0.35/0.2⌉=⌈1.75⌉=2\lceil 0.35/0.2 \rceil = \lceil 1.75 \rceil = 2⌈0.35/0.2⌉=⌈1.75⌉=2 (эрозия 0.4 м), высота ⌈1.8/0.1⌉=18\lceil 1.8/0.1 \rceil = 18⌈1.8/0.1⌉=18, ступень ⌊0.35/0.1⌋=3\lfloor 0.35/0.1 \rfloor = 3⌊0.35/0.1⌋=3 (0.3 м — меньше физических 0.35). Профиль по умолчанию (r=0.4r = 0.4r=0.4, ступень 0.4): радиус ⌈2.0⌉=2\lceil 2.0 \rceil = 2⌈2.0⌉=2 (та же эрозия), ступень ⌊4.0⌋=4\lfloor 4.0 \rfloor = 4⌊4.0⌋=4.     Access Key, sourceRadius. Шаг access_key_shop_to_goal стартует, когда агент у магазина (0, 0.35, −7).     6. Типичные ошибки, границы и проверка¶

    • Ждать обхода стен от GOAP move_to без графа. Прямой fallback — отрезок между ролями; NavMesh не используется (CP-MOVE-FALLBACK).
    • Обратное ребро. Граф ориентированный; путь назад требует своего ребра.
    • Устаревший route cost. Стоимость фиксируется при создании instance.
    • Частичный коридор. Не путь; CoreEngine корректно возвращает NoPath.
    • Другой профиль в overlay. Проверяйте параметры профиля агента, а не картинку default-NavMesh.
    • Синхронный bake. Новый профиль строится в момент запроса — возможна заметная пауза кадра INFERRED.
