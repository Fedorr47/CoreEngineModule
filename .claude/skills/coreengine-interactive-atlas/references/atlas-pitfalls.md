# Типовые дефекты атласа и способы их избежать

| Дефект | Причина | Решение |
|---|---|---|
| Поиск не работает из `file://` без сети | offline-плагин Material добавляет `https://unpkg.com/iframe-worker/shim` | `extra.polyfills: [assets/js/vendor/iframe-worker-shim.js]` (локальная копия, MIT) |
| Первый запрос в автотесте поиска без результатов | поле получило фокус до готовности обработчиков | в автотесте — прогревочный запрос; пользователь не затронут |
| Директива `@@diagram`/`@@code` осталась текстом | директива не в отдельном абзаце/строке | пустые строки вокруг директивы |
| KaTeX: `Undefined control sequence \*` | экранирование звёздочки для Markdown | `^{\ast}` |
| Блочная формула внутри списка не рендерится | `$$` в строке абзаца списка | отдельный абзац с отступом 4 пробела |
| Mermaid ломает слово посреди (`CommandCompon ent`) | `wrappingWidth` слишком мал | `flowchart.wrappingWidth: 480`, переносы — явным `<br/>` |
| Подпись ребра Mermaid перечёркнута линией | у SVG-подписи прозрачный фон | `themeCSS` с белым фоном `.edgeLabel rect` |
| Огромная LR-цепочка (3000 px) | горизонтальная раскладка длинной цепочки | `flowchart TB` |
| Наконечники стрелок в вычисленных SVG огромные | `markerUnits=strokeWidth` по умолчанию | `markerUnits="userSpaceOnUse"` |
| Стрелка уходит в кружок узла | конец линии в центре узла | укорачивать на радиус (`pad`) |
| Идентификатор в таблице ломается посреди слова | `overflow-wrap: anywhere` | `<wbr>` на границах camelCase при сборке |
| Неверная строка-якорь | текст встречается в объявлении и в определении (или в `friend`) | печатать строку резолва; задавать nth |
| Python here-doc портит `\1`, `\b`, `\.` | интерпретация экранирования оболочкой/строкой | редактировать файлы инструментом записи, не через `python - <<EOF` с regex |
