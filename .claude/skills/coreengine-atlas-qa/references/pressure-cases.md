# Pressure cases для навыков атласа

Каждый случай — ситуация, в которой без методики легко ошибиться, и ожидаемое поведение.

| # | Ситуация | Ожидаемое поведение | Механизм защиты |
|---|---|---|---|
| 1 | Старый PDF утверждает поведение, код изменился | Описать текущий код, PDF-утверждение → `CHANGED` в delta | `coreengine-source-audit` §Delta; `git diff old HEAD` |
| 2 | Формула без объяснения символов | Добавить обозначения, единицы, предпосылки, подстановку | чеклист `coreengine-theory-to-code` |
| 3 | «X вызывает Y», но вызова в коде нет | Не писать; найти строку вызова или пометить `INFERRED`/`NOT_VERIFIED` | реестр: каждая связь — якорь |
| 4 | Тестовый файл есть, тест не запускался, хочется написать PASS | Статус `NOT_RUN`/`SV` (наличие), без PASS | `coreengine-atlas-qa` §Отчётность |
| 5 | SVG нечитаем (3000 px, мелкий шрифт, наложения) | Переложить в TB/разделить на обзор+детали; скриншот | atlas-pitfalls, визуальный обзор |
| 6 | Страница тянет CDN (unpkg, шрифты) | Локальная копия ресурса; проверка блокирует сеть | `validate_site.py` (external), `qa_browser.js` (network) |
| 7 | Номер строки «подогнан» вручную | Только через якорь реестра | `references.py` падает на отсутствующем тексте |
| 8 | HEAD отстаёт от remote / снимок документа не предок HEAD | Остановиться и спросить, какой снимок описывать | `coreengine-source-audit` §Снимок |

## Фактический уровень проверки навыков (13.10.2026)

Выполнена структурная и ручная проверка: файлы с корректным frontmatter, ссылки на существующие инструменты,
случаи 3, 5, 6, 7, 8 реально встретились при создании атласа и были обработаны указанными механизмами.
Изолированный сравнительный запуск агента «без skill / со skill» **не выполнялся**; влияние навыков на поведение
другого агента не подтверждено.
